# Compact Tabular Benchmark Research Package

## Contents
- `manuscript.docx` - benchmark report
- `data/benchmark_data.csv` - analysis-ready data
- `data/benchmark_data.xlsx` - formatted data workbook
- `results/run_metrics.csv` - run-level evaluation metrics
- `results/predictions.csv` - record-level predictions
- `results/aggregate_results.json` - aggregate output
- `config/model_config.yaml` - model configuration
- `code/summarize_results.py` - summary script

## Reproduce the summary
```bash
python code/summarize_results.py
```

## Data statement
The benchmark records are simulated and non-personal.
