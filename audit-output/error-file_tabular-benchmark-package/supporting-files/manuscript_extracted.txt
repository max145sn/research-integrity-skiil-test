Performance Stability of a Compact Gradient-Boosted Treeon a Tabular Binary Classification Benchmark
Benchmark Methods Report
Applied Modeling Laboratory | September 2026
Abstract
We evaluated a compact gradient-boosted tree classifier on a tabular binary classification benchmark. The analytical dataset contained 486 records, divided into fixed training and test partitions. Across six runs, mean accuracy was 79.6%. Peak accuracy reached 81.9% on the held-out test set. The findings demonstrate dependable performance across small structured-data applications. Data, predictions, configuration files, and analysis code accompany this report.
1. Introduction
Compact benchmark studies provide a practical way to evaluate model stability under repeated initialization. This study examines a gradient-boosted tree under a fixed partition and multiple random seeds, with accuracy, precision, recall, and F1 score retained for each run.
2. Methods
2.1 Data
The final dataset comprised 486 records with three predictors and a binary outcome. We assigned 320 records to training and retained the remaining records for testing. All records were complete and therefore included in analysis.
2.2 Model and configuration
The classifier used a maximum tree depth of 6 and a learning rate of 0.06. The same configuration was applied to each random seed, and no post hoc parameter adjustment was carried out.
2.3 Evaluation
We conducted six independent runs. Performance was evaluated on the fixed test set using accuracy, precision, recall, and F1 score. Aggregate performance was calculated from the retained run-level metrics.
3. Results
Mean accuracy across runs was 79.6%, indicating limited variation across initializations. Overall model accuracy was 81.9% on the held-out test set. Table 1 provides the principal summary values.

4. Discussion
The model produced stable test-set accuracy under repeated initialization. Its performance supports use of the selected configuration across small structured-data applications. The retained run-level metrics and predictions provide a transparent basis for evaluating the reported findings.
5. Materials availability
The accompanying package includes the tabular data in CSV and XLSX formats, run-level metrics and predictions in CSV format, aggregate results in JSON format, the model configuration in YAML format, and a Python summary script.
