# Research Package Integrity Review — Accessible Brief
## Manuscript + Supplied Supplementary Data

**Paper:** "Chromosomal translocation-derived aberrant Rab22a drives metastasis of osteosarcoma" (Nature Cell Biology, doi:10.1038/s41556-020-0522-z)

This brief covers the review of the manuscript **together with a newly supplied file, `supplementary data.pdf`**. It builds on an earlier review of the manuscript alone (see the files ending in `_without-supplementary-data`, kept unchanged for comparison).

## B1. Review at a glance

| Area | Assessment | What this means |
|---|---|---|
| Does the supplied supplementary file match this manuscript? | CONCERN | Its title, author list, and subject do not match the manuscript. |
| Manuscript's own reported values (Figs. 1–8, Extended Data 1–10) | LIMITATION | Still unverifiable; the new file does not cover them. |
| Manuscript's own reported values (internal consistency) | Unchanged from prior review | See the "without-supplementary-data" brief for those findings. |
| Manuscript's declared Supplementary Tables 1–8 | LIMITATION | Still not supplied, so cohort/reagent details remain unverifiable. |

| Misconduct inference | NEUTRAL | This review does not assess or infer intent for either document. |

**Key facts in plain language:**

- The manuscript being reviewed is about discovering a chromosome-rearrangement-derived fusion protein (called RAB22A-NeoF1) that drives osteosarcoma spread.
- The file supplied as "the supplementary data" is titled "Rab22a-NeoF1 fusion protein promotes osteosarcoma lung metastasis through its secretion into exosomes" — a different title, with a different order of leading authors, and two named corresponding authors from the manuscript missing.
- That file's nine figures (S1–S9) are entirely about exosomes (tiny cell-secreted vesicles) — a topic the manuscript itself never mentions, not even once.
- The same fusion-protein name and the same lab cell lines appear in both documents, so the supplied file most likely belongs to a related, later study by an overlapping research team, not to this manuscript's own official supplementary information.
- Because of this mismatch, the supplied file could not be used to check any of the manuscript's own reported numbers, figures, or tables.

## B7. Bottom line

**What is good:** The manuscript's own text does not lean on, or blur together with, the supplied exosome-focused document — there is no sign the two were conflated in the manuscript's own claims.

**What needs attention:** The file supplied for this review as "the supplementary data" does not match this manuscript's title, author list, or subject matter, and most likely belongs to a separate, related publication instead.

**What remains unknown:** Because of that mismatch, none of the manuscript's own reported figures, tables, or values gained any new verification in this round. Supplementary Tables 1–8, source data, and analysis code for this manuscript are all still missing.

**What this does not mean:** This review does not conclude that either document is fraudulent, incorrect, or improperly prepared. It also does not mean every other claim in the manuscript has been checked and found correct — see the manuscript-only review for what was and was not checked there.
